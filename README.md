# Trabajo Práctico Integrador - Bases de Datos II

Proyecto de diseño e implementación de una base de datos NoSQL en MongoDB Atlas, con conexión mediante Node.js y automatización de respaldos.

## Archivos del repositorio
- `app.js`: Script principal en Node.js para la conexión y operaciones contra la base de datos.
- `package.json`: Configuración del proyecto y dependencias de Node.js.
- `backup.bat`: Script de automatización en Windows para generar backups de la base de datos.
- `Tpi_BD_Gabriel_Valdez.pdf`: Documentación técnica y diseño del proyecto.

## Nota sobre seguridad y credenciales
- Las credenciales reales fueron removidas de los archivos de código (`app.js` y `backup.bat`).
- Cualquier usuario, contraseña o cadena de conexión visible en las capturas del documento PDF corresponde a un entorno académico anterior y **se encuentra revocada/inactiva** (no tiene acceso a ninguna base de datos real).

## Tecnologías utilizadas
- Node.js / JavaScript
- MongoDB Atlas
- Scripts Batch (.bat) para automatización en Windows
